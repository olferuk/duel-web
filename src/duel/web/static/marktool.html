1. Точки (клик = поставить)

Башни: якорь = центр НИЗА башни.

2. Зоны выделения регионов

Выбери регион-зону → кликни ЛЕВЫЙ-ВЕРХНИЙ угол, затем ПРАВЫЙ-НИЖНИЙ. Левые углы прямые, правые скруглены общим радиусом.

Слои (двигать/масштаб)

Выбери слой — таскай мышью, колесо = масштаб, стрелки = 1px (Shift=10).

Клетки (кликами, по порядку)

В режиме клеток слои «прозрачны» для мыши — клики всегда ставят точки. «Клетки фона» — по клеткам, напечатанным на панораме. «Клетки полосы» — по клеткам самой полосы (запишутся в её координатах).
